# Operating Hypotheses

0계층 운영 가설의 정본 위치입니다.

운영 가설은 제품 기능 가설이 아니라 task 처리 방식, 정보 취합 방식, 전체 구현 플랜 수립 방식, 사일로/PR/review loop 운영 방식에 대한 가설입니다.

각 가설은 실행 전 채택 이유와 예상 병목을 먼저 적고, 실제 task/PR/silo 실행 후 결과와 병목을 이어 붙입니다.
