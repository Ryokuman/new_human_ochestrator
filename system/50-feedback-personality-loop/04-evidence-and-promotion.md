# 증거 등급과 승격 기준

## 증거 등급

| 등급 | 의미 |
|---|---|
| `explicit` | 사용자가 직접 말함 |
| `repeated` | 여러 번 반복됨 |
| `tentative` | 현재 상황에만 적용할 수 있음 |
| `rejected` | 이전 추론이 사용자에게 거부됨 |

## 전역 규칙 승격 후보 기준

전역 규칙 승격 후보로 검토할 수 있는 경우:

- 사용자가 명시적으로 말함
- 같은 유형의 miss가 여러 번 반복됨
- PR 리뷰나 QA 루프에서 계속 같은 문제가 발생함
- 적용해도 위험이 낮고 사용자 목표와 일치함

실제 전역 규칙 반영은 사용자가 원하는 주기로 여는 퍼스널리티 검토 세션에서 evidence를 분석한 뒤, 사용자 승인을 받은 경우에만 수행합니다.

## 사일로 전용으로 둘 경우

아래 항목은 기본적으로 사일로 전용 또는 프로젝트 전용으로 둡니다.

- 특정 프로젝트나 기능에만 해당
- 특정 PR의 실수
- 사일로가 context를 잘못 읽어서 생긴 문제
- 전역화하면 다른 작업에 방해될 수 있음
