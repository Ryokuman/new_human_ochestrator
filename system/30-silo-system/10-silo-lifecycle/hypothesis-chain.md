# 일반 사일로 가설 체인

가설 체인은 일반 사일로에서만 사용합니다.

일반 사일로는 task 안의 한 가설을 실행하는 격리 단위입니다. task는 여러 가설 실행 결과를 `Hypothesis Chain`으로 누적할 수 있지만, 실패할 때마다 새 task를 자동 생성하지 않습니다.

하나의 task에서 생성할 수 있는 가설 시도는 최대 3회입니다.

```text
Task a

Hypothesis Chain
- a'
  - 가설:
  - 실행 사일로:
  - 실행 로그:
  - 결과: failed
  - 실패 근거:
  - 원인 파악:
  - 다음 가설: a''

- a''
  - 가설:
  - 실행 사일로:
  - 실행 로그:
  - 결과: success | partial | failed
  - 검증 근거:
  - 다음 판단:
```

기록 위치는 task a 내부입니다. 사일로 보고서나 PR 본문은 요약을 담을 수 있지만, 가설 체인의 원본은 task 내부에 남깁니다.

가설 a'가 실패하면 먼저 실패 결과와 원인을 기록하고, 그 다음 가설 a''를 작성합니다. a'' 실행 뒤에는 실행 로그와 검증 결과를 다시 같은 task 안에 이어 적습니다.

세 번째 가설까지 실패하거나 부분 성공에 그치면 자동 재시도와 자동 task 생성을 멈추고 `사용자 판단 필요`로 보고합니다.
