# 개인 프로필 템플릿

## 1. 기본 정체성

- 내가 에이전트에게 불리길 원하는 이름/호칭: 미입력
- 내 역할: 미입력
- 주로 하는 일: 미입력
- 내가 장기적으로 만들고 싶은 시스템/제품: 미입력
- 에이전트가 나를 이해할 때 절대 놓치면 안 되는 한 줄: 미입력

## 2. 작업 취향

- 내가 좋아하는 작업 방식: 미입력
- 내가 싫어하는 작업 방식: 미입력
- 에이전트가 답답하게 느껴지는 순간: 미입력
- 에이전트가 잘하고 있다고 느끼는 순간: 미입력

## 3. 의사결정 기준

- 빠르게 밀어도 되는 일: 미입력
- 신중해야 하는 일: 미입력
- 절대 자동으로 하면 안 되는 일: 미입력
- 품질과 속도가 충돌하면 보통 어느 쪽을 우선하나요?: 미입력

## 4. 코드/제품 취향

- 좋은 코드라고 느끼는 기준: 미입력
- 싫어하는 코드 스타일: 미입력
- UI/UX에서 중요하게 보는 것: 미입력
- 버그를 다룰 때 선호하는 방식: 미입력

## 5. 사일로 운영 취향

- YOLO 모드에서 허용할 것: 미입력
- YOLO 모드에서도 금지할 것: 미입력
- 사일로가 막히면 어떻게 보고해야 하는지: 미입력
- 사일로가 PR description에 반드시 남겨야 하는 것: 미입력

## 6. 프로젝트 정보

- 사일로에 넣을 수 있는 프로젝트/레포 목록: 미입력
- 각 프로젝트의 보호 브랜치: 미입력
- 각 프로젝트의 기본 브랜치: 미입력
- 각 프로젝트에서 특히 조심해야 할 영역: 미입력
- 프로젝트별 secret/config는 어디서 읽어야 하는지: 미입력

## 7. 보고 방식

- 중간 보고 빈도: 미입력
- 완료 보고 형식: 미입력
- 너무 장황하다고 느끼는 기준: 미입력
- 너무 불친절하다고 느끼는 기준: 미입력

## 8. 퍼스널리티 갱신

- 한 번 말하면 바로 영구 규칙으로 올려도 되는 피드백: 미입력
- 여러 번 반복돼야 확정할 피드백: 미입력
- 절대 과잉 일반화하면 안 되는 피드백: 미입력
