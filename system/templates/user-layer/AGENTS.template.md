# User Layer

이 파일은 사용자별 판단 기준의 1계층 User SSoT 정본입니다.

## 목적

사용자 개입을 늘려 현재 결과만 개선하지 않습니다. 반복되는 협업 마찰을 Feedback으로 남기고, 별도 퍼스널리티 갱신 세션에서 검증한 판단 기준을 반영하여 이후 필요한 사용자 개입을 줄입니다.

## 유저 퍼스널리티

검증과 사용자 승인을 마친 현재 판단 기준만 기록합니다.

## 적용 경계

- 현재 사용자의 직접 지시가 우선합니다.
- 프로젝트 제품 불변 조건은 해당 Project AGENTS가 소유합니다.
- Task 실행 조건과 상태는 Task 문서와 silo `goal.md`가 소유합니다.
- Feedback 원문, 후보 퍼스널리티, 검증 시나리오와 검증 결과는 이 파일에 복사하지 않습니다.
