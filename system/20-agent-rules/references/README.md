# 에이전트 md 보강 reference

## 목적

이 폴더는 `AGENTS.md`, `CLAUDE.md`, 설치용 `SKILL.md`, 최종 오케스트레이터 프롬프트를 보강할 때 참고할 근거 자료의 구조를 정의합니다.

에이전트 md가 빈약하다고 판단되면 바로 규칙을 상상해서 추가하지 않습니다. 먼저 기존 프로젝트 운영 방식, PR 리뷰 피드백, 사용자 응답 취향, 보고 패턴을 reference로 정리한 뒤 공통 규칙으로 추출합니다.

## 저장 원칙

이 폴더에는 프로젝트 내부 실제 산출물을 그대로 복사하지 않습니다.

저장할 수 있는 것:

- 여러 프로젝트에 반복 적용할 수 있는 운영 패턴
- PR 리뷰에서 반복적으로 확인된 평가 기준
- 사용자 피드백에서 추출한 에이전트 행동 규칙 후보
- 에이전트 md를 보강할 때 사용할 질문과 점검표
- 프로젝트 자료를 어디에서 읽어야 하는지에 대한 reference index

저장하지 않는 것:

- 특정 프로젝트의 실제 issue/task 본문
- 특정 프로젝트의 QA 결과 원문
- L runner 결과, coverage report, page 목록
- secret, token, password, credential 값
- 승인되지 않은 단일 발화를 확정 퍼스널리티 규칙으로 만든 내용

## 사용 순서

에이전트 md를 보강할 때는 아래 순서로 진행합니다.

1. 현재 에이전트 md의 빈 부분을 식별합니다.
2. 부족한 부분이 프로젝트 맥락, PR 리뷰, 보고 방식, 퍼스널리티 중 무엇인지 분류합니다.
3. 해당 reference 문서를 먼저 읽습니다.
4. reference의 관찰과 패턴을 공통 규칙으로 압축합니다.
5. 장기 규칙 승격이 필요한 경우 사용자 승인 여부를 확인합니다.
6. 승인된 내용만 `AGENTS.md`, 최종 프롬프트, skill draft에 반영합니다.

## 문서 구성

| 문서 | 역할 |
|---|---|
| `agent-md-reinforcement-guide.md` | 에이전트 md를 보강하는 절차와 점검 기준 |
| `project-context-reference-template.md` | 기존 프로젝트 운영 정보를 reference로 정리하는 템플릿 |
| `pr-review-reference-template.md` | PR 리뷰 기준과 반복 피드백을 정리하는 템플릿 |
| `reporting-and-personality-reference-template.md` | 보고 방식과 퍼스널리티 후보를 분리해서 정리하는 템플릿 |

## 계층 판정

이 폴더의 문서는 0계층입니다.

프로젝트 내부 자료를 직접 저장하지 않고, 프로젝트 자료를 어떻게 참조하고 어떤 기준으로 에이전트 규칙으로 승격할지 정의하기 때문입니다.
