# PR 리뷰 reference 템플릿

## 목적

이 템플릿은 PR 리뷰에서 반복된 기준과 피드백을 에이전트 md 보강용 reference로 정리할 때 사용합니다.

PR 하나의 세부 논쟁을 보존하는 것이 아니라, 다음 사일로와 메인 오케스트레이터가 반복해서 적용할 수 있는 리뷰 기준을 추출합니다.

## 기본 정보

```text
reference 작성일:
대상 범위:
근거 PR:
관련 SSoT 항목:
```

## PR description 보강 후보

PR description에 반복적으로 필요한 섹션이나 문구를 적습니다.

```markdown
## 무엇을 했는가

## 변경 상세

### 문제 정의

### 기존 동작

### 문제가 된 이유

### 변경한 것

## 그래서 무엇이 되었는가

## 검증

## SSoT 승격 후보

## 승격하지 않을 항목

## 남은 위험
```

보강 후보를 쓸 때는 아래 항목을 확인합니다.

- 용어가 내부자 표현이면 실제 예시로 정의했는가
- 기존 동작과 문제가 된 이유를 분리했는가
- 변경 파일과 함수/정책 역할이 드러나는가
- coverage 개선형 task라면 기준 run, 변경 후 run, `초기 n -> 변경 후 n -> 목표 0` 수치가 있는가
- source/data 확인 필요, 정책 후속 필요, 예외 승인 후보가 page/item 단위로 분리됐는가

## 에이전트 md 반영 후보

|  | explicit/repeated/tentative | 승인됨/후보/제외 |

## 검수 질문

- 특정 PR에만 적용되는 지적을 전역 규칙으로 올리지 않았는가
- 이미 해결된 일회성 문제를 장기 규칙으로 만들지 않았는가
- PR description에서 승격 후보와 비승격 항목을 분리했는가
- 사용자 피드백이 있으면 현재 PR 수정과 장기 규칙 후보를 분리했는가
