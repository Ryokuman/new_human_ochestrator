# 보고 방식과 퍼스널리티 reference 템플릿

## 목적

이 템플릿은 사용자 피드백에서 드러난 보고 방식, 선택지 제안 방식, 퍼스널리티 후보를 정리할 때 사용합니다.

단일 반응을 장기 규칙으로 확정하지 않고, 관찰과 해석과 에이전트 대응을 분리하는 것이 목적입니다.

## 기본 정보

```text
reference 작성일:
피드백 출처:
적용 scope:
현재 PR 재작업 필요 여부:
장기 규칙 승격 필요 여부:
```

## 관찰

사용자가 실제로 말했거나 문서로 확인된 내용을 적습니다.

```text
-
-
```

## 해석

관찰에서 추론되는 작업 취향이나 보고 취향을 적습니다.

```text
-
-
```

## 에이전트 대응

다음 작업에서 에이전트가 어떻게 행동해야 하는지 적습니다.

```text
-
-
```

## 증거 등급

| 후보 | 등급 | 이유 |
|---|---|---|
|  | explicit/repeated/tentative/rejected |  |

## 승인 상태

| 규칙 후보 | 상태 | 다음 행동 |
|---|---|---|
|  | 승인됨/승인 필요/보류/제외 |  |

## 보고 형식 후보

필요하면 아래 보고 형식을 조정합니다.

```text
완료된 것
아직 안 된 것
목표 밖 산출물
SSoT 승격 후보
승격하지 않을 항목
다음 행동
```

## 검수 질문

- 사용자 피드백을 단순 불만으로 처리하지 않았는가
- 현재 PR 재작업과 장기 퍼스널리티 규칙을 분리했는가
- 승인되지 않은 단일 응답을 확정 규칙으로 쓰지 않았는가
- 보고 형식이 사용자의 다음 판단을 쉽게 만드는가
