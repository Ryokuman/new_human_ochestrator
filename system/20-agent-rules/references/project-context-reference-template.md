# 프로젝트 맥락 reference 템플릿

## 목적

이 템플릿은 기존 프로젝트 운영 정보를 에이전트 md 보강용 reference로 정리할 때 사용합니다.

프로젝트 내부 실제 SSoT를 0계층에 복사하는 문서가 아닙니다. 에이전트가 프로젝트 맥락을 어디서 읽고 어떤 공통 패턴을 따를지 정리하는 색인입니다.

## 기본 정보

```text
프로젝트 id:
reference 작성일:
근거 문서:
프로젝트 SSoT 위치:
repo 연결 방식:
보호 브랜치:
```

## 읽기 순서

프로젝트 작업 전에 읽어야 할 문서를 적습니다.

```text
1.
2.
3.
```
